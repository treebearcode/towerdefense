# Magitech Tower Defense

A 2D top-down tower defense game, built with Phaser 3. All sprites are
generated by Muse, in a magitech style mixing medieval stone and sci-fi
glowing runes.

Enemies animate facing their direction of travel, the glowing path is
drawn in code over cobble tiles, the map mixes six ground tiles, and the
HUD and shop are built from sprite panels, cards and buttons.

Play it: https://treebearcode.github.io/towerdefense/

## How to play

- Click a tower card at the bottom (Rune Archer $50, Crystal Mage $75,
  Energy Cannon $100), then click a free tile to place it.
- Click **Start Wave** (or Space) to send the next wave. 10 waves total.
- Enemies follow the glowing path from the spawn portal to the castle.
  Each one that reaches the castle costs lives (Orc Golems cost 2).
- Kills earn gold. Clearing a wave earns a $25 bonus.
- Click a placed tower to see its range and upgrade it (up to Lv3).
- P pauses, the 1x button toggles 2x speed, Esc cancels placement.

## Towers

- Rune Archer — fast, cheap, long range.
- Crystal Mage — heavy magic bolts.
- Energy Cannon — slow, splash damage.

## Enemies

- Armored Goblin — basic.
- Rune Skeleton — fast, low HP.
- Clockwork Orc Golem — slow tank, 2 lives on leak.

## Run locally

Serve `docs/` over HTTP (ES modules do not work from `file://`):

```
cd docs
python3 -m http.server
```

Then open http://localhost:8000/

## Files

- `docs/index.html` — page + boot guard (local Phaser, CDN fallback).
- `docs/main.js` — entry point.
- `docs/scene.js` — the game: map, waves, towers, enemies, projectiles.
- `docs/config.js` — balance, path, towers, enemies, waves. Tune here.
- `docs/assets/` — Phaser 3.60 plus the generated sprite PNGs.
